Инвестиции: как робот выбирает акции

Среднесрок 1–3 месяца (до 6) по ликвидным акциям MOEX. Слева на пульте — кого всегда мониторим. Справа — кого чек-лист сегодня пустил в работу. Не скальп, не «зелёная свеча = buy» и не прогноз индекса.

1. Идея простыми словами

Робот не гоняется за зелёной свечой. Он держит заранее заданный список бумаг, несколько раз за сессию прогоняет каждую через длинный чек-лист (фонд → ликвидность → макро → события → D1 → зона H4 → лента/кластеры) и ставит лестницу лимиток только при вердикте invest.

Бумага может годами жить слева и почти всегда быть skip — список наблюдения шире, чем сделки. Soft-уроки прошлых closes могут урезать размер или попросить подождать — сторону чек-листа не крутят.

2. Как проходит день

скан универсума→ чек-лист→ invest / watch / skip→ лестница · manage
  1. Берёт всех из списка наблюдения.
  2. По каждой проходит ступени pipeline (те же, что над графиками на пульте).
  3. Красная ступень = этот вход сейчас закрыт — видно почему.
  4. Только invest + Авто → fair-paper лестница, журнал и statement.
  5. Открытые позиции ведёт по пути цены: стоп, цель, частичная фиксация — не только «кончик» бара.

3. Список наблюдения

Фиксированный универсум ликвидных акций MOEX (нефть, металлы, банки, ритейл, IT). Число тикеров не «магическое» и не «победители дня»: слева столько, сколько записано в списке. Попасть слева ≠ пройти отбор на покупку. Отбор — справа: invest / watch / skip.

4. Чек-лист по ступеням

  1. Режим рынка IMOEX — можно ли лонг (или шорт в медвежьем рукаве).
  2. Фундамент и категория 1–3; четвёртая — не берём.
  3. Ликвидность, макро/сектор, корпоративные события.
  4. D1 в нужную сторону → зоны покупки на H4 / профиле объёма.
  5. Объём, кумулятивная дельта, кластеры Bid×Ask на M5 внутри зоны.
  6. Сайзинг по категории и soft-урокам, лестница лимиток, правила выхода.

5. Фундамент и категории

  • Кат.1 — надёжный, Debt/EBITDA ≤ 2.5, потенциал ≥ 30%, 8–10% sleeve.
  • Кат.2 — надёжный, умеренный потенциал 10–30%, 6–8%.
  • Кат.3 — слабее по фонду, потенциал ≥ 50%, 4–6%.
  • Кат.4 — не берём. Сектор ≤ 20% портфеля.

6. График и зоны

На пульте — VAP, кластеры, footprint. Робот считает зоны из профиля объёма; вы можете сверить глазами. Кластеры Bid×Ask на M5 — подтверждение внутри зоны, не отдельный сигнал «купить потому что зелёное».

7. Когда ставит заявки

  • invest — чек-лист зелёный; при Авто — лестница (часть в зоне, часть на докупку).
  • watch — интерес есть, входа нет.
  • skip — этот скан закрыл бумагу (не «забыть навсегда»).

8. Пока позиция жива

  • Fair-paper смотрит путь цены по барам с входа: стоп, TP, частичная фиксация.
  • Типичный выход: полная цель или ≈50% + БУ на остатке.
  • Зомби-лестницы снимает. Каждый close → soft-книга инвестиций.

9. Риск и выходы

  • Риск на сделку 0.5–1.5% капитала sleeve; RR ≥ 2:1.
  • ≈50% в ближней зоне / ≈50% на докупку.
  • Выход: полная фиксация на цели или 50% + перевод в безубыток.

10. Наблюдение и авто

  • Наблюдение — скан и pipeline без заявок.
  • Авто (paper) — лестницы, manage, журнал и statement.
  • Live — отдельный флаг, по умолчанию выкл.; без armed брокера — LIVE_GATED.
