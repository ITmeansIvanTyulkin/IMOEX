# trinity-shell — публичные Кости

Оболочка оценки продукта. **Нет** плейбуков, paper-сделок и боевых рекомендаций.

```bash
mvn -pl trinity-shell -am spring-boot:run
```

Открыть http://localhost:8080 — текст «ядро по подписке».

Оператор с соседним `../IMOEX-core` запускает полное приложение:

```bash
mvn -pl trinity-app -am spring-boot:run
```
